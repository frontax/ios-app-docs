# Privacy Policy

## Introduction

This Privacy Policy describes how the iOS app "Hiking Record" (the "App") handles user information. The App respects user privacy and is committed to protecting personal information.

## 1. Information Collected

The App collects the following information:

- Location data (used for GPS tracking)
- Photo library access (used for attaching photos to records and auto-detecting past hikes via photo scan)
- File access (used for importing GPX files, photos, and backup files)
- Microphone access (used for recording voice memos)
- Speech recognition access (used for voice memo transcription)
- Hiking-related data (mountain names, dates, elevation, distance, notes, course time plans and actuals, etc.)

## 2. Data Storage

All data is stored exclusively on your device. No data is transmitted to external servers. App data is included in device backups (iCloud or Mac/PC), enabling restoration when switching devices. The database and image files are protected by the device's encryption. Exported files (GPX, CSV, backup archives) are also protected by device encryption. Auto-backup data during hikes (GPS track points, session info) is stored in the app's private area and automatically deleted upon hike completion or cancellation.

## 3. Cache Data Handling

The App stores map tile and network cache data on your device to speed up map display. Cache data does not contain any personal information. You can view cache usage and delete cache data at any time from Settings → Data Management → Cache Management. Clearing the cache does not affect hiking records or downloaded offline maps.

## 4. Multilingual Support

The App supports Japanese and English display. Language switching is automatic based on device system settings; no language preference data is sent externally. All localized display data (mountain names, prefecture names, etc.) is contained within the app; no external translation services are used.

## 5. Statistics Handling

The App calculates statistics (monthly/yearly hike counts, cumulative elevation, walking distance, prefecture distribution, summit rates for all mountain categories, personal bests, etc.) from hiking records. Progress information displayed on highlight cards is also calculated from on-device data. All statistics are calculated and displayed locally; no data is sent to external servers.

## 6. Course Time Data Handling

The App records and manages course time plans (estimated time and rest time per checkpoint) and actuals (actual passing times). All calculations (time estimates based on trail distance and elevation gain) are performed on-device. Course time data is stored only on-device and is never sent to external servers.

## 7. Photo Handling

Photos saved in the App have their embedded location data (EXIF GPS) automatically removed for privacy protection. Other metadata such as capture date is retained. The photo scan feature analyzes photo location and timestamp data on-device to auto-detect hiking records. This analysis is performed entirely on-device; photo data and location information are never sent to external servers. Photos registered from scan results are saved with location data removed.

## 8. Voice Memos & Transcription

The App records voice memos and transcribes them on-device. All recording data and transcription results are stored only on-device. Speech recognition prioritizes on-device processing; Apple's speech recognition servers are used only when the device does not support on-device processing, in which case audio data is handled per Apple's Privacy Policy. Recording data is automatically deleted from the device after transcription.

## 9. AI Features (Highlight Card Caption Generation)

The App uses Apple Intelligence to auto-generate social media captions from hiking records. All AI processing is performed on-device; hiking record data is never sent to external servers. Custom prompts entered during regeneration are also processed only on-device. Generated text is reviewed and edited by the user before sharing. Template-based text generation is used on devices that do not support Apple Intelligence.

## 10. Backup & Restore

Backup files created by the App contain hiking record data (including course time plans and actuals) and attached images. Backup files are stored on-device and are not sent externally unless the user explicitly shares them. Backup files include SHA-256 hashes for integrity verification during restoration. Users are responsible for managing and sharing backup files.

## 11. Lock Screen & Dynamic Island Display

The App displays hiking information (distance, elevation, elapsed time, etc.) on the Lock Screen and Dynamic Island during hikes (Live Activity). All displayed information is processed on-device and never sent to external servers. The display is automatically cleared when the hike ends or is cancelled.

## 12. In-App Events

The App may offer limited-time in-app events (e.g., Summer Mountain Challenge). Event period determination and free tier limit changes are all performed on-device; no external server communication occurs. Event-related badges and other information are stored only on-device.

## 13. Review Requests

The App may display an App Store review request dialog using iOS standard functionality (StoreKit) when certain conditions are met. Review request display decisions (version, interval) are all made on-device; no external server communication occurs. Reviews are submitted through Apple's App Store; the App does not collect or store review content.

## 14. Social Media Sharing

Sharing of highlight cards and captions to social media is performed only when the user explicitly initiates the sharing action. Information handling on destination social media services is governed by their respective privacy policies.

## 15. Third-Party Disclosure

We do not provide, sell, or share user personal information with third parties.

## 16. External Service Communication

The App communicates with the following external services. No personal information is transmitted.

- GSI Tile Server (map tile image downloads)
- GSI Elevation API (trail elevation profile retrieval)
- Open-Meteo API (weather forecast data and sunset time retrieval)
- Overpass API / OpenStreetMap (trail and approach road data search)

Communications include the user's location range (latitude/longitude bounds) but no device-identifying or account information. All communication uses HTTPS (encrypted). A 15-second timeout prevents unresponsive connections from being maintained.

## 17. Audio Output

The App provides audio warnings when deviating from a route. All audio is generated on-device; no external server communication occurs.

## 18. In-App Purchases

In-app purchases (Pro version) are processed through Apple's payment system. The App does not collect or store payment information (credit card numbers, etc.). Purchase status is securely stored in the device's Keychain (secure storage).

## 19. Data Deletion

Deleting the App from your device removes all stored data (including hiking records, course times, source data for statistics, voice memo transcriptions, and cache data). Individual hiking records can also be deleted within the App. Deleting a record automatically recalculates associated statistics. Cache data can also be deleted separately from Settings → Data Management → Cache Management. Auto-backup data during hikes is deleted upon hike completion, cancellation, or dismissal in the recovery dialog. Data exported as backup files must be manually deleted by the user via the Files app or similar.

## 20. Changes to This Privacy Policy

This Privacy Policy may be changed without prior notice. Changes take effect upon publication on this page.
